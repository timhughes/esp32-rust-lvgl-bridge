# ESP32-S3-4848S040 (Guition Smart Display)

The **ESP32-S3-4848S040** (often sold as the Guition 4.0-inch 480×480 Smart Screen) is a popular integrated panel featuring an ESP32-S3-WROOM-1 module.

## Hardware Specifications
* **CPU**: ESP32-S3 dual-core Xtensa LX7 @ 240 MHz
* **Flash**: 16MB Quad-SPI Flash (80 MHz, DIO)
* **PSRAM**: 8MB Octal PSRAM (80 MHz, OPI)
* **Display**: 4.0" IPS LCD, 480×480 resolution
* **Driver IC**: Sitronix ST7701S
* **Bus Architecture**: 16-bit Parallel RGB interface + 3-wire 9-bit SPI control interface
* **Touch Digitizer**: Goodix GT911 capacitive touch over I2C

## Critical Engineering Quirks & Fixes

### 1. Xtensa Windowed ABI (`.cargo/config.toml`)
Rust on ESP32-S3 can compile using either Call0 ABI or Windowed ABI. When Rust functions are called directly from C tasks managed by ESP-IDF FreeRTOS (which always uses Xtensa Windowed ABI with register windows), an ABI mismatch causes immediate `IllegalInstruction` or `WindowUnderflow` panics.

**Fix**: Enable windowed features in `.cargo/config.toml`:
```toml
[target.xtensa-esp32s3-none-elf]
rustflags = ["-C", "target-feature=+exception,+windowed"]
```

### 2. ST7701S MDT Register (0xCD) & Vertical Stripes
On the Guition 4848S040 panel, register `0xCD` in Command 2 Bank 0 controls the **Memory Data Transfer (MDT)** mode. If left at the uninitialized default (`0x08`), the ST7701S expects 18-bit sub-pixel packing, causing 16-bit RGB565 parallel bus data to be scrambled into vertical stripes across the screen.

**Fix**: Send Command 2 Bank 0 with register `0xCD` set to `0x00`:
```c
// Command 2 Bank 0 Selection
{0xFF, (uint8_t []){0x77, 0x01, 0x00, 0x00, 0x10}, 5, 0},
// Disable MDT flag
{0xCD, (uint8_t []){0x00}, 1, 0},
```

### 3. Display Timings
Optimal timings for this panel with zero tearing and stable PSRAM bandwidth:
* **Pixel Clock (PCLK)**: 12 MHz (or conservative 10 MHz)
* **PCLK Inverted**: `false` (`.flags.pclk_active_neg = false`)
* **HSYNC**: Pulse width = 8, Front porch = 10, Back porch = 20
* **VSYNC**: Pulse width = 8, Front porch = 10, Back porch = 10
* **Color Order**: `LCD_RGB_ELEMENT_ORDER_RGB`
